Control recovery / takeover

If another browser still owns the display, enter the current date and time as DDMMYYHHMM (India time, changes every minute) or the fixed PIN set in credentials.h. Five wrong codes lock takeover for one minute.

The page keeps the session alive while it is open. If the browser closes or loses Wi-Fi, the display frees itself after 30 seconds. The recovery code is a convenience lock for a home network, not strong security.
